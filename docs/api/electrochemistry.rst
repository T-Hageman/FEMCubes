``femcubes.electrochemistry`` -- Electrochemistry Models
========================================================

Models for ionic transport in electrolytes, hydrogen in metals, and the
reactions at metal-electrolyte interfaces. The electrolyte page defines the
symbols shared by all of them; the activity page describes the activity
coefficients used by the electrolyte and the passivating surface.
